# My Profile API

## Introduction

This is a simple RESTful API Endpoint that displays my profile information along with a Dynamic cat fact fetched from an external API.

### Tech Stack

I used the following tech stack

**virtualenv** - virtual enviroment to create isolated development enviroment

**Pydantic** - class models for data validation

**Python3 , FASTApi and uvicorn server** -  server language and server framework


### Development Setup

## 1. Initialize and activate a virtualenv using:

```
python -m virtualenv env
source env/bin/activate
```

## 2. Install the dependencies:

```pip install fastapi, uvicorn, requests```


## 3. Run the development server:

```uvicorn myapi:app --reload```

## 4. Verify on the Browser

Navigate to the project homepage
